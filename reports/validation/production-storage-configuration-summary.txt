===========================================

- Production requires CAREER_BRIDGE_APPLICATION_STORAGE_BACKEND=dynamodb.
- Production requires CAREER_BRIDGE_WORKFLOW_STORAGE_BACKEND=dynamodb.
- Production requires CAREER_BRIDGE_DOCUMENT_STORAGE_BACKEND=s3.
- Production requires explicit application table, workflow table, and document bucket names.

- The override logs a prominent unsafe/demo-only warning and does not bypass other Reunia production checks.
- The live deployment validator expects persistent DynamoDB/S3 health metadata by default.
