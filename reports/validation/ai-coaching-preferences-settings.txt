AI Coaching Preferences settings migration
==========================================

Implemented
- Added Settings -> AI Coaching Preferences.
- Moved preferred answer style, response mode, audio response instructions,
  and clipboard response instructions into user settings.
- Existing values in legacy assistant_context records are used as migration
  fallbacks until the user saves Settings.
- Career Profile no longer renders, reads, or writes these preferences.
- Older Career Profile clients cannot overwrite the Settings-owned values.
- Existing Live Interview Assistance and Mock Interview services receive the
  new settings through the compatibility context adapter.
- Added English/French UI labels and validation.
