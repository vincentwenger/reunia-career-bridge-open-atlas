Application Builder startup persistence warning validation
==========================================================

Implemented behavior
--------------------
At Application Builder initialization, the app emits one WARNING log per Flask
application process with the resolved persistence configuration:

Application Builder persistence:
- workflow backend: process memory
- application backend: SQLite
- database path: <resolved APPLICATIONS_DB_PATH>
- safe only with one Gunicorn worker and Lightsail scale 1
- records may be lost during container replacement

Production path
---------------
The Docker image uses WORKDIR /app. The merged Réunia factory resolves the
default Application Builder database to:

/app/instance/career_bridge_applications.sqlite3

The warning uses the actual resolved path, including environment overrides and
:memory: during tests.
