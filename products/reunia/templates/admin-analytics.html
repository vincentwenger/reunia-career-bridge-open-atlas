How measurement worksPrivacy-conscious analytics +
  • Guests are counted using an anonymous first-party browser identifier.
  • Last active and active-user counts include browser activity plus durable product actions such as desktop sign-ins, recordings, meetings, documents, Live Q&A, and Action Center changes.
  • Active time and web active days count only while a browser tab is visible and recently used.
  • IP addresses, transcripts, recording audio, and document contents are not stored in analytics; only content-free metadata such as recording length and a coarse country code is used.
  • Product usage reads document metadata and saved-meeting metadata, never document or transcript content.
  • Desktop use counts successful desktop-client sign-ins; downloads are tied to an account only when the user is signed in.
  • Your administrator activity is excluded by default.
