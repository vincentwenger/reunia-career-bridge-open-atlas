# Career Bridge color system

Career Bridge uses a **Trust + Action** dual palette and applies the 60–30–10 principle.

## 60% — Canvas

- White: `#FFFFFF`
- Cool canvas: `#F8FAFC`
- Alternate surface: `#F3F7FA`
- Border: `#DCE4EC`
- Main text: `#1F2937`
- Muted text: `#64748B`

These colors dominate document review, forms, reports, and evidence-heavy screens so users can read for long periods without visual fatigue.

## 30% — Trust anchor

- Primary navy: `#1D4E78`
- Deep navy: `#143A5A`
- Slate blue: `#2F6F9F`
- Soft blue: `#EAF2F8`

Navy is used for the product shell, page heroes, trusted navigation structure, headings, and professional context.

## 10% — Action and progress

- Bridge teal: `#0F766E`
- Progress emerald: `#137A58`
- Primary action orange: `#C2410C`
- Orange hover: `#9A3412`
- Orange soft: `#FFF7ED`

Teal and emerald indicate active state, movement, completion, and progress. Orange is reserved for high-intent primary actions such as generating, saving, creating, submitting, or continuing the main workflow.

## Semantic colors

Success, warning, and error colors retain their own meaning. Red is never used decoratively, and orange warning states remain visually distinguishable from CTA orange through context, labels, and lighter warning surfaces.

## Accessibility

The primary navy, teal, and action orange used with white text meet WCAG AA contrast for normal text. Focus states use visible rings rather than color alone, and active or status states retain text labels and shape cues.
